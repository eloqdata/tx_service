# Store handler modules

`store_handler/` adapts the transaction service's `DataStoreHandler` contract to embedded RocksDB or the EloqDSS client/service boundary.

Read [`docs/09-store-handler.md`](../docs/09-store-handler.md) for the current architecture. EloqDSS build, configuration and operation instructions remain in [`eloq_data_store_service/README.md`](eloq_data_store_service/README.md).
